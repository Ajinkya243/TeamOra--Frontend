# 🧑‍💼 Team Ora - Team Management Dashboard

**Team Ora** is a full-stack team and resource management dashboard. It helps assign tasks to engineers, track their capacity, and organize workload efficiently. The app includes login authentication, project assignments, and real-time engineer tracking.

🔗 [Live Demo](https://team-ora-frontend.vercel.app/)

Backend repository - https://github.com/Ajinkya243/TeamOra---Backend

---

## ✨ Features

- 👤 Login and authentication using JWT
- 📋 Assign projects to engineers
- 📆 Track engineer capacity with start/end dates
- 👨‍💻 View assigned tasks for each engineer
- 🗂 Manage project and engineer data
- 📊 Real-time workload tracking

---

## 🛠️ Tech Stack

### Frontend
- React
- React Router
- Redux toolkit
- Axios
- CSS Modules
- Chartjs

### Backend
- Node.js
- Express.js
- MongoDB (Mongoose)
- JWT for authentication
- REST API for tasks, users, and capacity
